# NetGuard Mobile

تطبيق Android مبدئي لإدارة وتأمين شبكة تملكها.

## النسخة الحالية
- واجهة عربية للموبايل.
- فحص محدود للشبكة المحلية التي يتصل بها الهاتف.
- عرض الخدمات الشائعة المفتوحة على الأجهزة المكتشفة.
- أقسام الكاميرات والأمان والإعدادات.
- لا يتجاوز كلمات المرور ولا يحاول الدخول غير المصرح به.

## تشغيل على الكمبيوتر
```bash
pip install -r requirements.txt
python main.py
```

## إنشاء APK على Linux/WSL
```bash
pip install buildozer
buildozer android debug
```

سيظهر ملف APK داخل مجلد `bin/`.

## المرحلة التالية
1. اكتشاف ONVIF للأجهزة المتوافقة.
2. إدخال بيانات NVR/DVR محليًا.
3. دعم RTSP حسب الجهاز.
4. إعداد VPN آمن للوصول من خارج المحل.
5. تقرير أمني وتنبيهات.
